# training — 训练资料

本目录存放个人公路车功率训练的三块东西：**周期化计划**、**课型基座**、**课程包**。
全部为单文件 HTML（零依赖、可直接双击打开）与可被程序读取的 FIT / JSON。

> 身体数据口径：体重只看**晨起空腹（排便后）**；单日噪声 ±0.7kg，小于该量级不解读。
> 功率分区一律基于**码表设定 FTP 250W**（推定区间 245–258W，尚未实测）。

## 1. plan/ — 周期化计划

**`冬训计划_运动风_270W_75kg.html`**（主文件，单文件、无外部依赖）

- **目标**：2026/9–2027/3 冬训，FTP **260–270W @ 75kg**（3.47–3.60 W/kg）
- **五阶段**

  | 阶段 | 日期 | 主题 |
  |---|---|---|
  | p0 | 9/15 – 10/31 | 准备（补睡眠 + 打地基） |
  | p1 | 11/1 – 11/29 | 阈值重建 |
  | p2 | 11/30 – 1/3 | 阈值强化（引入 Z5） |
  | p3 | 1/4 – 2/7 | Z5 主攻 |
  | p4 | 2/8 – 3/7 | 专项 + 测试 |

- **决策门**：真 FTP 实测（MLSS 2×20min）——**10/13**、1/27、3/2
- **减载周**（均周一）：10/05、11/23、12/21、2027-01/18
- **测试周整周让路**：10/12、1/25、03/01

**怎么用**

- 表头「当前 FTP」**可直接改**，值存在浏览器 `localStorage`（键 `dongxun_ftp_v1`），
  改一个数 → 阈值课（94–100%）、VO2 课（106–120%）、C 包折算行、运动量总结**全表重算**
- 点日历任意日期 → 记录当天吃了什么 / 练了什么，自动算摄入与赤字
- 日历底部「**运动量总结**」：**按月** + **按阶段**两表，单位 **小时（h）**
  - 口径：合计 = 跑步 + 骑行 + 力量，**不含散步**；课次 = 有跑/骑/力的天数
  - 换算：**先按分钟加总，最后一次性折算小时**（逐行取整会漂）

**`今夜课程卡_高驰骑行课程_0911.html`** —— 单节课程的手机端卡片（出门前扫一眼）。

## 2. course-library/ — 课型基座

**`功率训练课库_附录A.html`**，整理自《自行车功率训练完全指南》**附录 A（印刷页 205–209）**。

- **12 个课型 × 6 种能力**，每张卡固定四读法：**强度 / 时长·组次 / 组间休息 / 目的**

  | 能力 | 课型 |
  |---|---|
  | 有氧耐力 | 有氧阈值、有氧节奏 |
  | 肌肉力量 | 力量重复 |
  | 速度技能 | 高踏频间歇 |
  | 肌肉耐力 | 甜区间歇、巡航间歇、节奏 Tempo |
  | 无氧耐力 | 快速集体骑行、VO₂max 间歇、火柴燃烧间歇 |
  | 冲刺能力 | 变速、爬坡冲刺 |

- 附带三块「不搬就没法执行」的内容：
  - **表 4.1 功率区间**（7 区，%FTP + RPE），旁列**按 FTP 现算的瓦数**（FTP 框可改）
  - **表 5.2 的 50-40-30-20-10 原则**（Alan Couzens，30km/h 基准）
  - **第 5 章的「火柴」**（不可再生的一次性高强度输出）
- ⚠️ 唯一非原文的内容是「瓦数换算」列与卡片底部折算行——那是算术，**原书只给 %FTP**，已标注。
  页脚逐条列出印刷页码，可回原书核对。
- 原书 PDF 为**扫描版无文字层**，本文件由逐页渲染后人工读取整理。

## 口径提醒

1. 所有瓦数派生自**码表设定 FTP 250W**（推定值，非实测）。凡涉及 IF / TSS / 分区，
   都应按此前提理解；真 FTP 实测后需按比例重算。
2. 计划里的「训练量」是**计划量**，不等于实际完成量。
3. 强度课一律「**功率 + 心率**」双锚，**心率上限 172**（LTHR 166）。
