# c-pack-8week — 8 周阈值 / VO₂ 课程包

来源：`8_week_Thres_vo2.zip`（16 节 FIT workout）。每节可直接导入码表 / Training Hub。

## 结构

**8 周 × 2 节 = 16 节**

- **SS 课**（甜区 → Over-Under）：占**周五**（计划中窗口 11/6 – 1/8，共 8 节）
- **VO2 课**（阶梯 → 微爆发）：占 **p2 周四 / p3 周二**

**W4、W8 为减量周**：SS 降到 85–98%、VO2 降到 115%，时长同步缩短。

## 强度基准

**全包以 %FTP 表达 → 无缩放系数**，可套用到任意 FTP。
`manifest.json` 中的瓦数按 **FTP = 250W** 折算，仅作参考；改 FTP 请按 `pct_ftp` 字段重算。

## 两类课的结构

### SS 课（甜区 / Over-Under）

- **甜区**：固定功率块，约 90% FTP（250W → 255W 左右）
- **Over-Under**：一组 = 下档 2min（92% 上下）+ 上档 1min（106% 上下）× 4。
  上档不彻底松、下档不彻底歇，用来制造"清不掉乳酸"的持续负荷
- 组间：1 区恢复

### VO2 课（阶梯 → 微爆发）

- **阶梯**：W1–W3，`5×4min → 6×4min`，强度 118% → 121%，组间 3–6min
- **微爆发（Microbursts）**：W5–W7，典型 `3×10`
  - **每组 = 10 个「30s @123–132% + 30s @57–60%」连续不停**，整组约 10min
  - 那 30s 的"松"只有 **57–60%（250W 下 143–150W）**，**不是休息，是低速巡航**；
    真正的休息只有**组间 4min @47–50%**
  - 设计意图：用短促反复把摄氧量顶到高位并维持，而不堆积神经肌肉疲劳

## ⚠️ 排期注意

模块首周阈上（>90% FTP）分钟会从 **45 → 81（≈1.8×）**。
周中质量课开始掉功率时，**先砍周五的 SS 课**，不要硬扛。

## manifest.json 字段

| 字段 | 说明 |
|---|---|
| `file` / `week` / `session` / `deload` | 文件名、周次、课型（SS/VO2）、是否减量周 |
| `total_min` / `work_min` | 总时长 / 主线时长（去热身放松） |
| `pct_range` / `pct_ftp` | 课程功率区间 / 逐段的 %FTP |
| `np_at_250` / `if_at_250` / `tss_at_250` | FTP 250W 下的 NP / IF / TSS |
| `hard_min_gt90pct` | 高于 90% FTP 的分钟数 |
| `steps[]` | 逐段：时长、%FTP 区间、250W 瓦数、phase（warmup/interval/cooldown） |

解析由 `fit-workout-plan-parser`（`fitdecode`）完成。
注意 FIT 的 `repeat_until_steps_cmplt` 循环块在 repeat 标记前**已输出过一遍**，
正确补 `rep-1` 遍——补 `rep` 遍会让时长与 TSS 虚高约 15%。
