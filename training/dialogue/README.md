## 口径提醒

1. 功率分区一律基于**码表设定 FTP 250W**；真 FTP 推定 260–268W。凡涉 IF / TSS / 分区，
   都按「设定值」理解。
2. **减脂期结论优先于涨功率结论**——本档案中后期的所有减量、砍课、赤字调整，
   服从此前提。
3. 体重只看**晨起空腹（排便后）**；单次称重信噪比约 1:25，**只认 7 天滚动均值斜率**。
4. 记录里出现的「预测」都是当时给出的区间，**未事后修饰**，命中与落空都保留。
